# WorkBuddy Skills

> 作者：Yannis Hu · 一套面向 WorkBuddy 的技能集合，包含**两个约束型技能**与**两个分析型技能**，用于在 AI 复杂任务的全流程施加质量约束，保证输出**可溯源、有时效、不编造**。

## 为什么做这个项目

大模型擅长生成，但容易犯两类错：**引用过时信息**、**编造来源与数字**。在求职调研、行业分析、政策核对等「信息准确 = 成败」的场景里，这两类错误是致命的。

这个仓库把「真实性」和「时效性」固化成两个可复用的技能（Skill），让 AI 在每次任务执行前就进入约束模式，从检索到输出全程接受规则校验——而不是事后才发现问题。

## 技能清单

### 约束型技能

| 技能 | 目录 | 触发词 | 约束内容 |
|------|------|--------|----------|
| 真实性约束 | `authenticity/` | 真实性、不要编造、必须有依据 | ① 每条结论标注来源类型 + 发布年份 + 核查日期；② 无法核实就写「无法核实」，岗位/薪资/内推/政策四类从严；③ 事实与推测明确区分 |
| 时效性约束 | `timeliness-3year/` | 时效性、3 年以内 | ① 信息源限指令时刻起 3 年以内；② 超期重要信息提示并标注年月；③ 时间不明按超期处理，政策/价格/人事从严到 12 个月 |

### 分析型技能

| 技能 | 目录 | 触发词 | 输出结构 |
|------|------|--------|----------|
| 行业分析 | `industry-analysis-test/` | 帮我分析这个行业 | 发展脉络 / 关键指标表格 / 未来 3–5 年潜力 / 可引用亮点 |
| 企业分析 | `enterprise-analysis/` | 帮我分析这个企业 | 核心数据 / 股权与组织 / 业务模式（全景占比 + 波特五力 + 波士顿矩阵）/ 高管发言与未来方向 / 第三方前景分析 |

## 设计思路

每个技能遵循三层结构：

1. **触发条件** —— 用户提到关键词即激活，激活时先声明约束已生效
2. **核心规则** —— 3 条硬规则，全程强制，不可绕过
3. **执行方式 + 收尾自检** —— 检索阶段主动核验来源时间戳，输出前逐条 checklist 自检

约束型与分析型可自由组合，形成「约束 + 分析」的完整工作流，例如：

```
以真实性和时效性约束执行：帮我分析 XX 企业
```

**中立性设计**：分析型技能不预设使用场景。用途（面试准备 / 投资判断 / 竞品对标等）由用户声明，未声明时按通用中性口径输出，不擅自添加场景化内容。

## 安装方法

1. 下载对应技能目录（或整个仓库）。
2. 把技能文件夹（如 `authenticity/`）复制到 WorkBuddy 的用户技能目录：
   - macOS/Linux：`~/.workbuddy/skills/`
   - 确保路径结构为 `~/.workbuddy/skills/authenticity/SKILL.md`
3. 新建一个会话，技能即自动加载。

## 使用示例

```
以真实性和时效性约束执行：帮我分析 XX 行业
```

两个约束会同时覆盖整个任务的执行过程。

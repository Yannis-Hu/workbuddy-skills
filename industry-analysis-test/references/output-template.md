## 常见错误（避免）

- 只给数字不给来源 → 每个数字必须可溯源
- 把媒体转述当成一手报告 → 标注「经 XX 引述」
- 观点和事实混写 → 机构观点单独标注「分析性内容」
- 篇幅失控 → 正文（不含表格）600–900 字
- **替用户预设用途** → 用户未说明时，不加「面试 / 求职 / 投资」等场景化标题、使用提示或建议章节
